Wings is the daemon that actually runs your servers: it talks to the Docker daemon, streams console output, serves files and SFTP, and takes backups. One Wings instance runs per physical node, and it registers with the panel as a node. Panasaurus Wings is a ground-up rewrite in Rust that speaks the same protocol — drop-in compatible with the Wings v1.13.3 HTTP API the panel already speaks.

## What changes under the hood

- **Rust, not Go.** Faster cold starts, lower idle memory, and a single static binary — installed to `/usr/local/bin/panasaurus-wings` from prebuilt release archives, with a source build as fallback.
- **A documented API.** Every endpoint ships an OpenAPI document at `/openapi.json` — all 38 routes the panel expects — so integrations are written against a spec instead of guessed from panel source.
- **Native TLS with ACME.** The API listener terminates TLS itself and can obtain certificates automatically over the TLS-ALPN challenge, no reverse proxy or certbot required.
- **More backup drivers.** Local tar/zip/7z, S3, deduplicated chunked backups, btrfs and zfs snapshots, restic, and Proxmox Backup Server — the panel picks per node.
- **SFTP that behaves.** Per-user connection limits, sliding-window rate limits, `ssh-ed25519` host keys persisted across restarts, and protocol extensions modern clients actually use.
- **Per-server bandwidth limits** and filesystem-level disk quotas (btrfs subvolume, zfs dataset, or XFS project quotas) when you want them enforced, not just reported.

## Requirements

- Ubuntu 22.04+ or Debian 12 (apt-based, systemd)
- amd64 or arm64 CPU
- Docker — Wings cannot run servers without it; the installer sets it up if missing
- A reachable panel with a node created for this machine
