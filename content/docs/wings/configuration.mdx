---
title: Wings configuration
description: Reference for /etc/panasaurus/config.yml — panel connection, API listener, system storage, SFTP, and Docker settings.
---


Wings reads its configuration from YAML (by default `/etc/panasaurus/config.yml`). You can generate a configuration with `panasaurus-wings --configure`. After editing the configuration file, restart the service:

```bash
systemctl restart panasaurus-wings
```

## Example configuration

```yml
uuid: 00000000-0000-0000-0000-000000000000
token_id: NODE_TOKEN_ID
token: NODE_TOKEN_SECRET_KEY_32_CHARS
remote: https://panel.example.com
jwt_audience: https://node.example.com:8081

api:
  host: 127.0.0.1
  port: 8081
  upload_limit: 100
  ssl:
    enabled: false
    cert: /etc/panasaurus/tls/fullchain.pem
    key: /etc/panasaurus/tls/privkey.pem
    acme_domain: node.example.com
    acme_email: admin@example.com
    acme_production: false

system:
  data: /var/lib/panasaurus/volumes
  default_disk_limit_mb: 20480
  sftp:
    enabled: true
    bind_address: 0.0.0.0
    bind_port: 2022
    max_handles: 64

docker:
  executable: docker
  user: "1000:1000"
  tmpfs_size: 64
  container_pid_limit: 512
  cpu_period: 100000
  cpu_shares: 0
  memory_overhead_percent: 0
  installer_limits:
    memory: 1024
    cpu: 100
    timeout_seconds: 3600
  network:
    name: null
    dns: []
    enable_icc: false

allowed_origins:
  - https://panel.example.com

allowed_mounts: []

downloads:
  allowed_hosts: []

limits:
  jobs: 8
  sftp_connections: 64
  transfer_bytes: 68719476736

recovery:
  enabled: true
  restart_crashed: true
  detect_clean_exit: false
  crash_cooldown_seconds: 60
  stop_timeout_seconds: 120
```

## Core settings

- `remote`: The URL of your Panasaurus Panel instance.
- `token_id` & `token`: Node credentials for authenticating with the panel's remote API.
- `jwt_audience`: The node connection URL. **Must match the node's URL configured in the panel exactly.**

## API listener (`api`)

- `host`: The IP address for the API listener (default `127.0.0.1`). If TLS is disabled, Wings requires binding to a loopback address.
- `port`: Port for HTTP/HTTPS requests (default `8081`).
- `upload_limit`: Maximum file upload size in MiB (1 to 10240 MiB).
- `ssl`: TLS settings. Supports path-based certificates (`cert`, `key`) or Let's Encrypt TLS-ALPN via `acme_domain`.

## System & SFTP (`system`)

- `data`: Absolute path to server files (e.g., `/var/lib/panasaurus/volumes`). Must be accessible by Docker.
- `default_disk_limit_mb`: Fallback disk allocation limit for servers in MiB.
- `sftp.enabled`: Enables or disables the internal SFTP service.
- `sftp.bind_address` & `sftp.bind_port`: SFTP listener address and port (default port `2022`).
- `sftp.max_handles`: Maximum open file handles per SFTP session (1 to 512).

## Docker settings (`docker`)

- `executable`: Name or path of the Docker binary (default `docker`).
- `user`: User and group ID passed to container execution (e.g. `"1000:1000"`).
- `tmpfs_size`: Size of `/tmp` in MiB inside server containers.
- `container_pid_limit`: Maximum number of processes allowed per container.
- `cpu_period`: Docker CPU CFS period limit in microseconds.
- `installer_limits`: Memory, CPU, and timeout limits applied when running egg installation scripts.

## Concurrency & limits (`limits`)

- `jobs`: Maximum simultaneous background job operations (1 to 64).
- `sftp_connections`: Maximum concurrent SFTP connections allowed (1 to 4096).
- `transfer_bytes`: Maximum file/archive transfer size in bytes (e.g., 64 GiB).

## Recovery & crash handling (`recovery`)

- `enabled`: Enables automated crash recovery and monitoring for server containers.
- `restart_crashed`: Automatically restarts containers that terminate unexpectedly.
- `crash_cooldown_seconds`: Cooldown duration in seconds before attempting to restart a crashing server.
- `stop_timeout_seconds`: Timeout in seconds given to a container when gracefully shutting down before forcing termination.
