---
title: Wings installation
description: Install the Panasaurus Wings daemon — Rust node daemon for the panel — with the automated installer or manually.
---


Wings is the daemon that runs server containers: it communicates with Docker, streams console and event websockets, manages files and SFTP connections, and handles backups and transfers. One Wings instance runs per node.

## Requirements

- Linux OS (Ubuntu 22.04+ or Debian 12 recommended)
- amd64 or arm64 CPU
- Docker — Wings requires Docker to manage containers
- A reachable panel with a node record created for this machine

## Panel-side preparation

Before installing on the node, collect these values from the panel:

1. **Node setup.** Create a node under **Admin → Nodes**. Set the connection URL (for example `http://127.0.0.1:8081` or `https://node.example.com:8081`). Note the numeric node ID.
2. **Application API key.** Generate an API key under **Admin → Application API**. Wings uses this key during initial configuration.

<Callout type="warn" title="The connection URL must match exactly">
  The connection URL is stored as `jwt_audience` in the daemon configuration.
  It must match the panel's node address byte for byte — including scheme and port.
</Callout>

## Option A — the automated installer

```bash
bash install.sh --wings --panel-url https://panel.example.com \
  --node-url https://node.example.com:8081 \
  --token YOUR_APPLICATION_API_KEY --node 1
```

The installer:

1. Detects system architecture and installs required packages
2. Downloads `wings-linux-amd64.tar.gz` (or `arm64`) from [Wings releases](https://github.com/panasaurus/wings/releases)
3. Installs the executable to `/usr/local/bin/panasaurus-wings`
4. Generates `/etc/panasaurus/config.yml` using `panasaurus-wings --configure`
5. Generates the systemd service unit and starts `panasaurus-wings`

## Option B — manual installation

Download a release archive and install the binary:

```bash
curl -fsSLO https://github.com/panasaurus/wings/releases/latest/download/wings-linux-amd64.tar.gz
tar -xzf wings-linux-amd64.tar.gz
install -m 0755 panasaurus-wings /usr/local/bin/panasaurus-wings
```

Create the node configuration. The destination file must not exist yet:

```bash
mkdir -p /etc/panasaurus /var/lib/panasaurus/volumes
export PANASAURUS_APPLICATION_TOKEN="YOUR_APPLICATION_API_KEY"
panasaurus-wings --configure \
  --panel-url https://panel.example.com \
  --node-id 1 \
  --token-env PANASAURUS_APPLICATION_TOKEN \
  --node-url https://node.example.com:8081 \
  --config /etc/panasaurus/config.yml
unset PANASAURUS_APPLICATION_TOKEN
chmod 0600 /etc/panasaurus/config.yml
```

Generate and install the systemd unit:

```bash
panasaurus-wings --systemd-unit --config /etc/panasaurus/config.yml \
  > /etc/systemd/system/panasaurus-wings.service
systemctl daemon-reload
systemctl enable --now panasaurus-wings
```

## Verifying the installation

```bash
systemctl status panasaurus-wings
journalctl -u panasaurus-wings -f
```

Check that the service is active and running without errors. In the panel, the node status indicator should turn green.
