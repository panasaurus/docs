Panasaurus is a game server management platform built on the Pterodactyl and Pyrodactyl lineage. It consists of three core components:

| Component | Description | Location |
|-----------|-------------|----------|
| **Panel** | Laravel 12 + React 19 control plane with the Blueprint extension framework pre-installed. Deployed via Docker Compose. | [github.com/panasaurus/panel](https://github.com/panasaurus/panel) |
| **Wings** | The node daemon, written in Rust. Compatible with the panel's remote API, featuring native TLS and integrated SFTP server. | [github.com/panasaurus/wings](https://github.com/panasaurus/wings) |
| **Images** | Core container bases for Java, Node.js, Python, Go, Rust, and game servers published to a single GHCR namespace. | `ghcr.io/panasaurus/images` |

An installer script (`install.sh`) automates deploying the panel, Wings, or both on Debian/Ubuntu systems.

## Key Features

- **Built-in Blueprint support.** The Blueprint extension framework ships pre-installed in the panel image. Extensions run without manual file patching, and the admin panel includes an extension marketplace.
- **Containerized architecture.** The panel runs in a multi-stage Docker container stack. Wings communicates directly with the host Docker daemon to manage game server instances.
- **High-performance Rust node daemon.** Wings is implemented in Rust using Tokio and Axum for low resource overhead and fast container operations.
- **Unified container image namespace.** All official runtime images live under `ghcr.io/panasaurus/images`.

## Quick start

On a fresh Ubuntu 22.04+ or Debian 12 machine as root:

```bash
curl -fsSL https://panasaurus.com/install.sh | bash
```

Choose whether to install the panel, Wings, or both. For non-interactive deployment, pass flags directly:

```bash
bash install.sh --panel
bash install.sh --wings --panel-url https://panel.example.com \
  --node-url https://node.example.com:8081 --token YOUR_API_KEY --node 1
```

See [Automated installer](/docs/panasaurus/automated), [Panel installation](/docs/panasaurus/installation), and [Wings installation](/docs/wings/installation) for full documentation.
