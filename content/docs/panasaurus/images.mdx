title: Panasaurus Images
description: Container runtime images for Panasaurus game servers, built for linux/amd64 and linux/arm64.
---


Panasaurus Images provides maintained container images for game servers and runtimes under a single registry namespace: `ghcr.io/panasaurus/images`.

```bash
docker pull ghcr.io/panasaurus/images:java_21
```

## Available Images

Images live in one GitHub Container Registry repository and are identified by tag:

| Runtime / Category | Tags |
|--------------------|------|
| Java (Temurin / OpenJ9) | `java_8` … `java_26`, `*_j9` variants, `java_latest` |
| Node.js | `nodejs_12` … `nodejs_24`, `nodejs_latest` |
| Python | `python_3.7` … `python_3.13`, `python_latest` |
| Go | `go_1.14` … current, `go_latest` |
| Rust & .NET | `rust`, `dotnet_7`, `dotnet_8`, `dotnet_9` |
| Operating System | `alpine`, `debian` |
| Games | `rust`, `source`, `hytale`, `conan_exiles` |
| Installers | `installer_*` tags for egg installation scripts |

Refer to the [images repository](https://github.com/panasaurus/images) for a full listing of active tags and Dockerfiles.

## Build and Maintenance

Images are built via GitHub Actions CI:
- Dockerfiles and entrypoint scripts are validated with `hadolint` and `shellcheck`.
- Multi-architecture images are built and pushed for `linux/amd64` and `linux/arm64`.
- Image definitions are configured in `.github/images.json`.

## Migrating Image Tags

Eggs referencing legacy `ghcr.io/pterodactyl/yolks:*` image tags can be updated to `ghcr.io/panasaurus/images:*`. See the [migration guide](/docs/panasaurus/migration) for SQL update scripts.
