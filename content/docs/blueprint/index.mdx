[Blueprint](https://blueprint.zip) is an extension framework for Pterodactyl-based panels. It enables adding admin pages, dashboard components, custom themes, and backend routes without modifying core panel source files.

Panasaurus ships with Blueprint pre-installed and integrated into the panel container.

<Callout type="info" title="Managing Extensions">
  For instructions on installing and managing extensions via the admin UI or CLI, see the [Extensions guide](/docs/panasaurus/extensions).
</Callout>

## Integration Overview

- **Automatic Seeding:** Blueprint database migrations and seeders execute during initial panel container startup.
- **Extension Compatibility:** Extensions built for Blueprint and Pterodactyl remain compatible. The `Pterodactyl\` PHP namespace is retained for extension compatibility.
- **In-App Marketplace:** Search and browse extension listings under **Admin → Panasaurus → Marketplace**.
- **Frontend Extension Points:** Extensions hook into defined React extension slots using a routes registry.
