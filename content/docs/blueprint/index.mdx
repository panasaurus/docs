[Blueprint](https://blueprint.zip) is the extension framework for Pterodactyl-family panels — extensions add admin pages, dashboards widgets, theme changes, and backend services without forking the panel. In most panels, Blueprint is something you install after the fact: download an extension, run a patch script, hope the panel update next month doesn't clobber it.

Panasaurus ships Blueprint **pre-installed and integrated**. It is part of the image, seeded on first boot, and kept in sync with the panel itself — there is nothing to patch and no version drift to manage.

<Callout type="info" title="Operator guide">
  If you want to install and manage extensions rather than write them, the
  [Extensions page](/docs/panasaurus/extensions) in the Panasaurus section
  covers the admin area, the marketplace, and the CLI.
</Callout>

## What integration means

- **First boot seeds the framework.** Migrations and the Blueprint seeder run automatically when the panel container starts for the first time — no post-install script.
- **The extension ecosystem just works.** Extensions written for Blueprint and Pterodactyl install and run unchanged. The `Pterodactyl\` PHP namespace is preserved on purpose: it is what keeps existing extensions compatible.
- **A marketplace in the admin area.** A live, cached view of the Blueprint ecosystem directory with search and filters, under **Admin → Panasaurus → Marketplace**.
- **Frontend extension points.** The panel's React 19 app exposes the same extension slots Blueprint users already know — extensions register through a routes registry instead of patching compiled bundles, so nothing needs rebuilding.
