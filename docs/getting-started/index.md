# Getting started

Three pages, three ways in:

1. **[Quick start](/docs/quick-start)** — one command installs the panel, the daemon, or both. Start here if you have a fresh server.
2. **[Panel installation](/docs/panel-install)** — the full panel walkthrough: requirements, Docker setup, environment variables, first login.
3. **[Daemon installation](/docs/daemon-install)** — install `panasaurus-wings` on a game node, manually or with Docker.
4. **[Your first node](/docs/first-node)** — wire the daemon to the panel, create allocations, launch a server.

If you already run Pterodactyl, jump straight to [migrating images](/docs/images-migration) and the [daemon compatibility notes](/docs/daemon) — everything else speaks the same protocol.
